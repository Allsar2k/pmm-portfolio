# Security Policy

This is a static website: there is no server, no accounts, no database and no stored visitor data.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting (**Security** tab → **Report a vulnerability**) rather than opening a public issue. You will get a reply within 7 days.

Useful details to include:

- the page or file affected
- what an attacker could do
- steps to reproduce

## Supported versions

Only the latest deployment of the `main` branch is supported.
